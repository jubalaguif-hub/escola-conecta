# Clina / Escola Conecta — Layout Premium 2026

Esta versão aplica a linguagem visual premium aprovada na conversa:

- azul-marinho → azul royal em degradê como assinatura visual;
- menu ativo com degradê e profundidade;
- cards maiores, bordas suaves e sombras discretas;
- nova identidade visual para filtros, indicadores, tabelas e painéis;
- Agenda com resumo semanal e cards de indicadores;
- menus Aulas, Presenças, Cobranças, Comunicações e Configurações agora possuem páginas navegáveis no mesmo padrão visual;
- Usuários e Professores preservam as funcionalidades existentes e herdam a nova base visual global;
- responsividade mantida para desktop e mobile.

## Observação
As novas páginas de Aulas, Presenças, Cobranças, Comunicações e Configurações são uma camada visual/protótipo pronta para conexão aos dados reais. As rotas e a navegação já estão preparadas.

A instalação de dependências não foi incluída no ZIP. Rode `npm install` ou `npm ci` no seu ambiente antes de executar o projeto.
