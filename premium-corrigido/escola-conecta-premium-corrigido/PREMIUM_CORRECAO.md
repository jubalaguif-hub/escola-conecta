# Correção visual Premium

Esta versão foi refeita sobre a base funcional original do projeto.

Principais mudanças:
- Agenda aproximada ao mockup aprovado: topbar, menu completo, suporte, perfil, filtros com período, cabeçalho em degradê, alternador Semana/Mês e cards de resumo.
- Usuários, Professores e Cursos mantêm a lógica/ações Supabase originais, com nova camada visual premium.
- Shell administrativo unificado com a mesma identidade visual azul degradê.
- Páginas Aulas, Presenças, Cobranças, Comunicações e Configurações mantidas como páginas de interface quando ainda não há lógica de negócio correspondente na base original.

Não substitua `.env.local` pelo conteúdo deste pacote. Preserve o arquivo do seu Codespace.
